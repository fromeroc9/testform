# `testform login` y `logout`

```bash
testform login [nombre-host]
testform logout [nombre-host]
```

Los comandos `testform login` y `testform logout` administran los tokens de autenticación con Providers remotos y servidores de estado en la máquina local del desarrollador.

---

## `testform login`

Solicita interactivamente un token de API (por ejemplo: un Personal Access Token de GitHub) y lo almacena de manera segura en la configuración del usuario (`~/.testform.d/credentials.json`):

```bash
$ testform login github.com

Testform must obtain an API token to interact with github.com.
If you don't have a token, generate one at https://github.com/settings/tokens.

Enter a value: ghp_xxxxxxxxxxxxxxxxxxxx

Success! API token saved in ~/.testform.d/credentials.json.
```

Una vez guardado, Testform utiliza este token automáticamente para las operaciones del Provider sin necesidad de exportar manualmente `GITHUB_TOKEN` en las variables de entorno.

---

## `testform logout`

Elimina las credenciales guardadas para el host especificado:

```bash
$ testform logout github.com
Success! Stored token for github.com removed.
```

---

## Códigos de Salida

- `0`: Operación completada exitosamente.
- `1`: Credenciales no válidas o fallo de permisos de almacenamiento.

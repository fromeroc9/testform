# `testform graph`

```bash
testform [opciones globales] graph [opciones]
```

El comando `testform graph` genera una representación visual del grafo de dependencias de toda tu infraestructura de pruebas.

Genera la salida en el formato canónico **DOT** (compatible con Graphviz, PlantUML y visualizadores web como GraphvizOnline).

## Qué Muestra el Grafo

1. **Jerarquía**: Relaciones estructurales entre recursos `testplan`, `testrun` y `testcase`.
2. **Asociaciones de Reglas**: Qué archivos `.case.feature` se encuentran vinculados a qué archivos `.run.feature`.
3. **Orden de Ejecución**: El orden topológico en el que Testform ejecutará y sincronizará los recursos durante `apply`.

## Ejemplo de Ejecución Real

```bash
$ testform graph
digraph G {
  rankdir = "RL";
  node [shape = rect, fontname = "sans-serif"];
  "testcase.login_valid" -> "testrun.sprint_42";
  "testcase.checkout_coupon" -> "testrun.sprint_42";
  "testrun.sprint_42" -> "testplan.release_2_0";
}
```

## Exportación a Imagen (PNG / SVG)

Envía la salida directamente a `dot` (Graphviz):

```bash
# Renderizar en formato vectorial SVG:
testform graph | dot -Tsvg -o test-graph.svg

# Renderizar en formato de mapa de bits PNG:
testform graph | dot -Tpng -o test-graph.png
```

## Códigos de Salida

- `0`: Grafo generado exitosamente.
- `1`: Error al procesar los archivos de pruebas o resolución de dependencias cíclicas.

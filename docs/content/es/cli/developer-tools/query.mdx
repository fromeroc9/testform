# `testform query`

```bash
testform [opciones globales] query [opciones] <expresion-filtro>
```

El comando `testform query` incorpora un motor de consulta y filtrado (similar conceptualmente a `jq`) para consultar secciones específicas de tu infraestructura de pruebas directamente desde el archivo de estado.

## Expresiones de Filtrado

Las expresiones permiten filtrar por etiquetas, campos personalizados, milestones o estados de ejecución:

```bash
# Localizar todos los casos de prueba con etiqueta @smoke
testform query '.resources[] | select(.scope == "testcase" and (.tags | contains(["smoke"])))'

# Listar todas las corridas con estado fallido
testform query '.resources[] | select(.scope == "testrun" and .attributes.status == "failed")'

# Extraer URLs de todos los issues pertenecientes al milestone "Sprint 42"
testform query '.resources[].instances[].attributes | select(.milestone == "Sprint 42") | .url'
```

## Opciones del Comando

| Opción | Por Defecto | Descripción |
| :--- | :--- | :--- |
| `-json` | `true` | Emite los resultados en formato JSON. |
| `-raw` | `false` | Emite cadenas literales sin comillas envolventes. |

## Ejemplo de Ejecución Real

```bash
$ testform query -raw '.resources[].instances[].attributes.url'
https://github.com/mi-org/web-app/issues/104
https://github.com/mi-org/web-app/issues/105
https://github.com/mi-org/web-app/issues/106
```

## Códigos de Salida

- `0`: Consulta evaluada exitosamente.
- `1`: Expresión no válida o error al leer el archivo de estado.

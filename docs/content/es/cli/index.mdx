# Resumen de la CLI y Opciones Globales

La interfaz de línea de comandos (CLI) de Testform es la herramienta operativa central para gestionar tu infraestructura de pruebas. Diseñada bajo las convenciones de HashiCorp Terraform, ofrece un flujo de trabajo intuitivo, predecible y consistente.

---

## Sintaxis de Comandos

```bash
testform [opciones globales] <subcomando> [opciones] [argumentos]
```

---

## Opciones Globales

Las opciones globales pueden anteponerse a cualquier subcomando:

| Opción Global | Alias | Descripción |
| :--- | :--- | :--- |
| `-chdir=DIR` | `-C` | Cambia el directorio de trabajo a `DIR` antes de ejecutar el comando. |
| `-scope=SCOPE` | `-s` | Limita la ejecución a `testcase`, `testrun` o `testplan`. |
| `-projectId=ID`| — | Sobrescribe el ID de GitHub Projects V2 configurado en `testform.yml`. |
| `-no-color` | — | Desactiva los colores ANSI (ideal para servidores de logs continuos). |
| `-json` | — | Emite la salida estructurada en formato JSON para automatización y CI/CD. |
| `-help` | `-h` | Muestra la ayuda detallada y opciones para cualquier comando. |
| `-version` | `-v` | Imprime la versión instalada de Testform. |

---

## Sintaxis con Alcance al Inicio (Scope-First)

Testform permite anteponer el identificador de alcance antes del subcomando para facilitar una escritura más fluida:

```bash
# Sintaxis estándar:
testform plan -scope=testcase

# Sintaxis equivalente con scope al inicio:
testform testcase plan
testform testrun apply
testform testplan destroy
```

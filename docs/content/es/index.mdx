## Flujo de Inicio Rápido en 60 Segundos

Comienza a tratar tus pruebas como código en solo 4 pasos:

<Steps>
### 1. Instala el CLI de Testform
Instala el paquete globalmente mediante npm:
```bash
npm install -g @fromeroc9/testform
```

### 2. Inicializa tu Repositorio
Crea la configuración declarativa `main.yml` e inicializa backends y proveedores:
```bash
testform init
```

### 3. Previsualiza los Cambios Especulativos
Inspecciona el plan de conciliación antes de sincronizar recursos:
```bash
testform plan
```

### 4. Aplica el Estado y Ejecuta tus Pruebas
Sincroniza atómicamente con tu plataforma y lanza la matriz de ejecución:
```bash
testform apply -auto-approve
testform suite tags "[@smoke]"
```
</Steps>

## Cómo Empezar en 60 Segundos

Adopta Testform en tu proyecto existente en 4 sencillos pasos:

<Steps>
### 1. Instala Testform
```bash
npm install -g @fromeroc9/testform
```

### 2. Inicializa tu Espacio de Trabajo
```bash
testform init
```
Configura el backend de estado (Local, OCI, AWS S3 o Azure) y conecta tus plataformas de issues (GitHub Projects V2, GitLab o Jira).

### 3. Planifica tus Pruebas de Forma Especulativa
```bash
testform plan
```
Calcula el grafo de dependencias y revisa qué recursos se agregarán o actualizarán antes de realizar cambios reales.

### 4. Concilia y Ejecuta tus Runners
```bash
testform apply -auto-approve
testform suite
```
Aplica el estado atómicamente con bloqueo distribuido y lanza tus suites automatizadas de Playwright, API y K6.
</Steps>

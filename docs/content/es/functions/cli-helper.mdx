# CLI Helper: `testform functions`

El CLI de Testform cuenta con un comando dedicado para explorar y poner a prueba las funciones de expresiones directamente en la consola. Esto te permite verificar la salida exacta de una expresión antes de incorporarla en tus archivos `locals.yml` o `variables.yml`.

---

## 1. Listar el Catálogo Completo

Ejecutar `testform functions` imprime el índice de todas las funciones disponibles con su firma y resumen:

```bash
testform functions
```

## 2. Obtener Ayuda de una Función Específica

Indica el nombre de cualquier función para inspeccionar sus argumentos esperados y ejemplos de uso:

```bash
testform functions format
```

Salida:
```text
Testform Expression Function: format
  Category:    String & Text
  Signature:   format(format, ...args) -> string
  Description: Formats a string using verbs (%s for string, %d for integer, %j for JSON, %% for literal %).

Arguments:
  - format [string]: Format string containing placeholders.
  - args [any...]: Values to interpolate.

Examples:
  $ format("%s/%s", var.base_url, "api/v1")
    => "https://example.com/api/v1"
  $ format("run-%03d", 5)
    => "run-5"
```

Otro ejemplo para colecciones:
```bash
testform functions coalesce
```

## 3. Evaluar Expresiones en Vivo (`--eval`)

La opción `--eval` procesa cualquier expresión válida a través del lexer, parser y evaluador AST de Testform, mostrando el resultado formateado y su tipo de dato correspondiente:

### Formateo de Cadenas Compuestas
```bash
testform functions --eval "format('https://%s.empresa.com/api/%s', lower('STAGING'), 'v2')"
```
Salida:
```text
Expression Evaluation:
  Input:  format('https://%s.empresa.com/api/%s', lower('STAGING'), 'v2')
  Type:   string
  Result: "https://staging.empresa.com/api/v2"
```

### Comprobación de Pertenencia en Listas
```bash
testform functions --eval "contains(['dev', 'staging', 'prod'], 'dev')"
```
Salida:
```text
Expression Evaluation:
  Input:  contains(['dev', 'staging', 'prod'], 'dev')
  Type:   boolean
  Result: true
```

### Operaciones de Lógica Ternaria
```bash
testform functions --eval "length('test') > 2 ? 'largo' : 'corto'"
```
Salida:
```text
Expression Evaluation:
  Input:  length('test') > 2 ? 'largo' : 'corto'
  Type:   string
  Result: "largo"
```

### Transformación de Objetos JSON
```bash
testform functions --eval "jsondecode('{\"enabled\": true, \"retries\": 3}')"
```
Salida:
```text
Expression Evaluation:
  Input:  jsondecode('{"enabled": true, "retries": 3}')
  Type:   object
  Result: {
  "enabled": true,
  "retries": 3
}
```

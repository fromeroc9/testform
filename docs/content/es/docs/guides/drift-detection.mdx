# Deteccion de Deriva (Drift)

Supervisa de forma continua si los casos de prueba en tus herramientas externas han sido modificados fuera de Git.

## Que es la Deriva (Drift)?

La deriva ocurre cuando un usuario modifica el titulo, la descripcion o el estado de un caso de prueba directamente en la interfaz grafica de Jira o GitHub Projects V2, omitiendo el proceso de revision en Git.

## Deteccion Automatizada en CI/CD

Puedes configurar un flujo de trabajo programado (cron nocturno) en GitHub Actions o GitLab CI que ejecute:

```bash
testform plan -detailed-exitcode -refresh=true
```

- Si el codigo de salida es `0`: No existe deriva; Git y los sistemas remotos estan perfectamente alineados.
- Si el codigo de salida es `2`: Se detecto deriva. El pipeline puede emitir una notificacion a Slack o generar un issue de alerta.

## Restauracion del Estado Autoritativo

Para eliminar cualquier modificacion manual externa y forzar que la definicion de Git vuelva a gobernar:

```bash
testform apply -auto-approve
```

Testform sobrescribira la desviacion en la API remota, garantizando que el repositorio Git permanezca como la **unica fuente de verdad**.

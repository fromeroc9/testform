# Rutas de Migracion hacia Testform

Descubre como modernizar tu estrategia de pruebas y migrar casos existentes a Testform sin perder historial ni metadatos.

## Guias de Migracion

- **[Migracion desde Hojas de Calculo](./from-manual):** Transforma matrices en Excel o Google Sheets a archivos declarativos `.feature`.
- **[Migracion desde Jira / Zephyr / QMetry](./from-jira):** Importa casos de prueba existentes y asocialos al ledger de estado mediante `testform import`.
- **[Actualizacion de Ledger de Estado](./state-migration):** Procedimientos seguros para actualizar versiones del formato de estado y migrar entre proveedores cloud.

# Backend: Local

El backend `local` almacena el estado directamente en tu disco local dentro de un archivo llamado `testform.state`.

Es el backend predeterminado que se utiliza cuando no se declara ningún bloque `backend` en `testform.yml`.

---

## Configuración

```yaml
# En testform.yml
backend:
  type: local
  config:
    path: "testform.state"  # Opcional, por defecto ./testform.state
```

---

## Cuándo Utilizar el Backend Local

- **Desarrollo Local**: Para experimentar con nuevos escenarios antes de subirlos a Git.
- **Proyectos Individuales**: Cuando un único ingeniero administra el repositorio.
- **Prototipado Rápido**: Ciclos de retroalimentación inmediatos sin requerir credenciales en la nube.

---

## Advertencias Importantes

> [!WARNING]
> NO subas `testform.state` a repositorios públicos de Git si tus pruebas contienen metadatos sensibles. Para equipos productivos, configura siempre un backend remoto en la nube (AWS S3, Azure Blob o Google Cloud Storage) con bloqueo de estado distribuido.

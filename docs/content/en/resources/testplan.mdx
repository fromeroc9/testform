# Resource: testplan

The `testplan` resource is the highest architectural tier in Testform. It groups and orchestrates multiple `testrun` executions across different browsers, mobile devices, staging environments, or microservices into a unified release sign-off board.

---

## File Matching Rules

1. Files ending with `.plan.feature` (e.g. `release-v2.0.plan.feature`).
2. Any `.feature` file that contains the `@testplan` tag at the `Feature:` level.

---

## Example Resource Definition

```gherkin
@testplan
Feature: Release 2.0 Qualification Plan
  Overall verification plan for Release 2.0 deployment across all platforms.

  Background:
    * milestone = "Release 2.0"
    * assignees = ["qa-director", "lead-devops"]

  Rule: web-regression.run.feature
  Rule: mobile-ios.run.feature
  Rule: mobile-android.run.feature
  Rule: performance-benchmarks.run.feature
```

---

## Provider Mapping (GitHub Example)

When applied, the `testplan` compiles into:
1. **An Umbrella Epic Issue**: Titled `"Release 2.0 Qualification Plan"`.
2. **Aggregated Status Rollup**: Links to each individual Testrun Issue, showing progress bars and completion percentages.
3. **Release Milestone Alignment**: Binds all associated runs to the target release milestone.

---

## Commands for Testplans

```bash
# Preview plan modifications
testform plan -scope=testplan

# Apply the test plan to GitHub
testform apply -scope=testplan

# Close or archive the test plan
testform destroy -scope=testplan
```

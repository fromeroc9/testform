# Resource: testcase

The `testcase` resource is the foundational building block in Testform. Each individual Gherkin `Scenario` within a testcase file corresponds to an independent Issue created and synchronized in GitHub (or your configured Provider).

---

## File Matching Rules

Testform identifies testcase files using either of the following criteria:
1. Files ending with `.case.feature` (e.g. `login.case.feature`).
2. Any `.feature` file that contains the `@testcase` tag at the `Feature:` level.

---

## Example Resource Definition

```gherkin
@testcase @auth @regression
Feature: Authentication Scenarios

  Background:
    * milestone = "Sprint 42"
    * assignees = "qa-lead"

  @smoke @tc-1
  Scenario: Valid credentials allow login
    Given the user navigates to "/login"
    When the user enters valid credentials
    Then the user is redirected to "/dashboard"
```

---

## Provider Mapping (GitHub Example)

When Testform applies this scenario, the GitHub Provider translates it into an Issue with the following attributes:

| Gherkin Element | GitHub Issue Attribute | Generated Value |
| :--- | :--- | :--- |
| **Scenario Title** | **Issue Title** | `Valid credentials allow login` |
| **Steps** (`Given`/`When`/`Then`) | **Issue Body (Markdown)** | Formatted Markdown code block containing the exact step sequence. |
| **Tags** (`@auth`, `@regression`, `@smoke`) | **Issue Labels** | `auth`, `regression`, `smoke` (the `@testcase` and `@tc-1` tags are stripped). |
| **Identity Tag** (`@tc-1`) | **State Identifier** | `login.case.feature::@tc-1` (recorded in `testform.state`). |
| **DSL Variable** (`* milestone`) | **Milestone** | Resolves "Sprint 42" to the GitHub Milestone ID. |
| **DSL Variable** (`* assignees`) | **Assignees** | Assigns the issue to `@qa-lead`. |

---

## Managing Testcase Resources

```bash
# Preview changes to all test cases
testform plan -scope=testcase

# Apply changes idempotently
testform apply -scope=testcase

# Destroy all test cases (closes the corresponding issues)
testform destroy -scope=testcase
```

# Official GitHub Provider

The GitHub Provider is Testform's built-in reference provider. It bridges local Gherkin scenarios with GitHub Issues, Milestones, and Projects V2 boards.

---

## Configuration in `testform.yml`

```yaml
version: "1.0"

provider:
  type: github
  config:
    owner: "my-organization"
    repository: "web-app"
    tokenEnv: "GITHUB_TOKEN"    # Environment variable holding your Personal Access Token
    projectId: 1                # Optional: GitHub Project number (e.g. github.com/orgs/.../projects/1)
```

---

## Required Token Permissions (Scopes)

Your GitHub Personal Access Token (or `secrets.GITHUB_TOKEN` in GitHub Actions) requires the following permissions:

| Permission | Access Level | Reason |
| :--- | :--- | :--- |
| `repo` (or `issues: write`) | Read & Write | Creating, updating, and closing issues, labels, and comments. |
| `project` (or `project: write`) | Read & Write | *(Optional)* Adding issues to Projects V2 boards and updating custom field values. |

---

## Features Supported

- **Issue Checklists**: Automatically formats `testrun` scenarios into clickable GitHub Task Lists.
- **Projects V2 Sync**: Sets custom fields, iterations, and single-select statuses in modern GitHub Projects.
- **Milestone Resolution**: Matches milestone names from Gherkin (`* milestone = "Sprint 42"`) to existing GitHub milestone IDs automatically.
- **Markdown Tables**: Renders step tables and execution details as clean, readable Markdown tables in issue bodies.

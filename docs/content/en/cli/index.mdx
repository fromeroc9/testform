# CLI Overview & Global Options

The Testform Command Line Interface (CLI) is the central operational tool for managing your testing infrastructure. Designed following the conventions of HashiCorp's Terraform, it provides an intuitive, predictable workflow.

## Command Syntax

```bash
testform [global options] <subcommand> [options] [arguments]
```

## Global Options

Global options can be provided before any subcommand:

| Global Option | Alias | Description |
| :--- | :--- | :--- |
| `-chdir=DIR` | `-C` | Switches working directory to `DIR` before executing the command. |
| `-scope=SCOPE` | `-s` | Limits execution to `testcase`, `testrun`, or `testplan`. |
| `-projectId=ID`| — | Overrides the default GitHub Projects V2 ID configured in `testform.yml`. |
| `-no-color` | — | Disables ANSI color escapes (ideal for plain log aggregators). |
| `-json` | — | Emits machine-readable JSON output for automated scripting and CI/CD pipelines. |
| `-help` | `-h` | Displays detailed usage and help text for any command. |
| `-version` | `-v` | Prints the installed Testform version. |

## Scope-First Syntax

Testform allows placing the scope identifier before the command for a more natural CLI syntax:

```bash
# Standard syntax:
testform plan -scope=testcase

# Equivalent scope-first syntax:
testform testcase plan
testform testrun apply
testform testplan destroy
```

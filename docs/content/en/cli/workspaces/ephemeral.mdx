# `testform ephemeral`

```bash
testform ephemeral <subcommand> [options] [args]
```

The `testform ephemeral` command manages disposable, temporary QA test sandboxes. It allows engineers and CI pipelines to spin up isolated test runs, execute suites, collect metrics, and tear down the environment cleanly without polluting production boards.

## Subcommands

### 1. `testform ephemeral up`
Provisions an ephemeral test sandbox:
```bash
testform ephemeral up -name="pr-412-sandbox" -ttl="2h"
```

### 2. `testform ephemeral list`
Lists all currently active ephemeral sandboxes and their remaining time-to-live:
```bash
$ testform ephemeral list
SANDBOX ID       NAME               CREATED         TTL REMAINING
eph-9812         pr-412-sandbox     25m ago         1h 35m
```

### 3. `testform ephemeral down`
Tears down and destroys an active ephemeral sandbox:
```bash
testform ephemeral down eph-9812
```

## Exit Codes

- `0`: Ephemeral operation completed.
- `1`: Sandbox not found or teardown failed.

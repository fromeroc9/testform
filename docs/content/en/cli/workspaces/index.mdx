# Sessions & Workspaces

Commands for managing multiple parallel environments, provider authentication sessions, and ephemeral sandbox testing.

## Available Commands

- **[`testform workspace`](./workspace):** Manages parallel isolated state ledgers (`list`, `new`, `select`, `delete`).
- **[`testform login` / `testform logout`](./login-logout):** Authenticates and revokes sessions against cloud storage and remote providers.
- **[`testform ephemeral`](./ephemeral):** Provisions, attaches, and tears down short-lived ephemeral environments for isolated PR testing.

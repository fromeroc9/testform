# Core Workflow

Core workflow commands manage the complete lifecycle of planning, applying, synchronizing, and tearing down declarative test resources.

## Core Lifecycle Commands

- **[`testform init`](./init):** Initializes the workspace, scaffolds standard directories, and sets up state backends.
- **[`testform plan`](./plan):** Produces a speculative execution plan comparing local code against the state ledger and remote APIs.
- **[`testform apply`](./apply):** Executes planned mutations, acquires distributed mutexes, and persists ledger changes.
- **[`testform refresh`](./refresh):** Queries remote provider APIs and updates local state records to reflect out-of-band mutations.
- **[`testform destroy`](./destroy):** Safely tears down and deletes managed resources across external testing providers.

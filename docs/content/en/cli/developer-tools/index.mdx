# Developer Tools

Productivity utilities for developers and QA engineers to streamline formatting, static validation, analysis, and execution reporting.

## Available Developer Tools

- **[`testform suite`](./suite):** Orchestrates automated test suite runs through configured test runners (Playwright, Cypress, Vitest).
- **[`testform validate`](./validate):** Statically verifies `.feature` syntax and governance validation policies.
- **[`testform fmt`](./fmt):** Re-formats Gherkin files and YAML configurations to canonical code standards.
- **[`testform diff`](./diff):** Displays fine-grained line diffs between local specifications and state records.
- **[`testform show`](./show):** Inspects binary plan files or state ledger snapshots in human-readable or JSON formats.
- **[`testform query`](./query):** Queries repository test resources using boolean tag filters and metadata criteria.
- **[`testform graph`](./graph):** Outputs Directed Acyclic Graphs (DAG) in Graphviz DOT or Mermaid formats.
- **[`testform report`](./report):** Compiles executive compliance and test execution summaries into HTML, Markdown, or JUnit XML.

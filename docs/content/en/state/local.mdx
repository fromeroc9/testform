# Backend: Local

The `local` backend stores state directly on your local disk in a file named `testform.state`.

This is the default backend used when no `backend` block is declared in `testform.yml`.

---

## Configuration

```yaml
# In testform.yml
backend:
  type: local
  config:
    path: "testform.state"  # Optional, defaults to ./testform.state
```

---

## When to Use the Local Backend

- **Local Development**: Testing new test scenarios before pushing to Git.
- **Solo Projects**: Where only one engineer manages the repository.
- **Prototyping**: Fast feedback loops without cloud credentials.

---

## Important Warnings

> [!WARNING]
> Do NOT commit `testform.state` to public Git repositories if your tests contain sensitive metadata. For production teams, always configure a remote cloud backend (AWS S3, Azure Blob, or Google Cloud Storage) with distributed state locking.

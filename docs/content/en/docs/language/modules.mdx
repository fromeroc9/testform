# Modules (Modular Architecture)

**Modules** in Testform package, parameterize, and reuse complex testing workflows (authentication, shopping cart seeding, teardown routines) across different feature suites and repositories, matching Terraform's module architecture.

---

## Invocation Modes

Testform provides two complementary methods for consuming modules:

### 1. Direct Tag Invocation (`@module`)

Invoke a module directly over a `Background:` step or a `Scenario:` using the `@module` tag:

```gherkin
Feature: Inventory Management

  Background:
    @module(source="./modules/auth/login.feature", scenario="Admin Login", vars={user: "admin", role: "SuperAdmin"})
    Given admin session is active

  Scenario: Create new product in catalog
    When admin registers product "SKU-991"
    Then stock reflects 100 units
```

### 2. Centralized Declaration in `main.yml`

Register reusable module instances with default input values and output bindings:

```yaml
# main.yml
modules:
  auth_staging:
    source: "./modules/auth/login.feature"
    vars:
      base_url: "${var.app_url}"
      user: "staging_tester"
      password: "${var.test_password}"
    outputs:
      token:
        value: "${testcase.modules/auth/login.feature.@login.token}"
```

## Remote Modules (Git Module Registry)

Testform downloads and verifies modules hosted in remote Git repositories during `testform init`:

```yaml
modules:
  shared_auth:
    source: "git::https://github.com/my-org/test-modules.git//auth?ref=v1.2.0"
    vars:
      base_url: "https://qa.company.com"
```

The URL adheres to standard Terraform module syntax:
- **Prefix:** `git::https://...`
- **Subdirectory:** `//path/submodule`
- **Branch / Tag:** `?ref=v1.2.0` or `?ref=main`

---

## Isolated Module Outputs

Values exported by a child module are namespaced under `module.<name>.<output>`:

```gherkin
Scenario: Consume session token produced by child module
  Given request header is set to "Authorization: Bearer ${module.shared_auth.token}"
  When user queries protected endpoint
  Then response status is 200 OK
```

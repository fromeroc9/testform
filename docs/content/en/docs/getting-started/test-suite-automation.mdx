# Test Suite Automation

Connect your declarative test cases with real test automation runners including Playwright, Cypress, and Vitest using the `testform suite` command.

## How It Works

Testform does not replace specialized test runners like Playwright or Vitest; it serves as the **declarative orchestrator and state persistence layer**.

1. **Definition:** Test cases are authored in `.feature` files with behavioral tags (`@smoke`, `@auth`, `@billing`).
2. **Selection:** `testform suite` resolves tag boolean logic to determine the exact set of scenarios to execute.
3. **Dispatch:** Testform invokes your configured runner (e.g., `npx playwright test`).
4. **Recording:** Test results produce an immutable declarative run artifact (`@tr-[id]`) reconciled with your state ledger and remote platforms.

```text
+-----------------------+
|  testform suite       |
|  -tags="@smoke"       |
+-----------+-----------+
            |
            v
+-----------------------+
|  Filter & Resolution  | ===> [auth.case.feature, checkout.case.feature]
+-----------+-----------+
            |
            v
+-----------------------+
|  Runner (Playwright)  | ===> npx playwright test tests/e2e/auth.spec.ts
+-----------+-----------+
            |
            v
+-----------------------+
|  Test Run Artifact    | ===> tests/runs/smoke-20261021.run.feature
|  (@tr-smoke-run-001)  | ===> testform apply (Syncs Jira/GitHub)
+-----------------------+
```

## Runner Configuration in main.yml

Declare your runner binary and execution flags in `main.yml`:

```yaml
testform:
  required_version: ">= 1.0"
  backend: local

suite:
  runner: "playwright"
  command: "npx playwright test"
  options:
    reporters: ["json", "list"]
    timeout: 30000
    parallel: true
```

## Running a Suite

To execute all test cases tagged with `@smoke`:

```bash
npx testform suite -tags="@smoke"
```

## Advanced Boolean Tag Filtering

The `-tags` parameter supports full boolean logic (`and`, `or`, `not`):

```bash
# Run critical or smoke tests that are not flaky
npx testform suite -tags="(@priority-critical or @smoke) and not @flaky"

# Run billing component tests intended for staging
npx testform suite -tags="@component-billing and @staging"
```

## CI/CD Pipeline Automation

Add the suite command into your continuous delivery pipeline to execute and reconcile on every commit:

```yaml
- name: Run Certification Suite
  run: |
    npx testform suite -tags="@smoke" --ci
    npx testform apply -auto-approve
```

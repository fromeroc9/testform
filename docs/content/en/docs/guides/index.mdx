# Practical Guides and Architectural Patterns

Learn how to configure Testform for high-availability enterprise environments, distributed engineering teams, and advanced testing architectures.

## Available Guides

- **[Multi-Cloud Backends](./multi-cloud-backends):** Setting up state persistence across Oracle Cloud Infrastructure (OCI), Amazon S3 with DynamoDB, Azure Blob Storage, Google Cloud Storage, and Local storage.
- **[Distributed State Locking](./state-locking):** Mutex lease mechanics, preventing concurrent CI/CD collisions, and safe lock recovery.
- **[Data-Driven Testing](./data-driven):** Designing complex test matrices with `Scenario Outline` and `Examples` tables.
- **[Modular Architecture (@module)](./modules):** Composing reusable test workflows (such as login and checkout) across multiple `.feature` files.
- **[Drift Detection and Alerts](./drift-detection):** Continuous monitoring pipelines detecting out-of-band modifications in external QA tools.

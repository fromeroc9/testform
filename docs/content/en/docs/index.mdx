# Testform Documentation

Welcome to the official documentation for **Testform**, the declarative **Test-as-Code (TaC)** framework for quality engineering and version-controlled test management in Git.

The documentation is organized across five core chapters:

### 1. [Getting Started](./getting-started)
Learn how to install Testform, initialize your workspace, author your first declarative tests, and orchestrate automated runner suites.
- [Installation and Quickstart](./getting-started)

- [Running Tests and Reconciliation](./getting-started/running-tests)
- [Test Suite Automation](./getting-started/test-suite-automation)

### 2. [Testform Test (Test-as-Code)](./test-as-code)

- [Policies and Quality Gates](./test-as-code/policies)

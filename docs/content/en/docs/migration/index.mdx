# Migration Paths to Testform

Learn how to modernize your quality assurance operations and adopt Testform without losing test history or metadata.

## Migration Guides

- **[Migration from Spreadsheets](./from-manual):** Convert legacy Excel or Google Sheets test matrices into declarative `.feature` files.
- **[Migration from Jira / Zephyr / QMetry](./from-jira):** Ingest existing test issues into the state ledger utilizing `testform import`.
- **[State Ledger Upgrades](./state-migration):** Safe workflows for state schema upgrades and cross-cloud backend migrations.

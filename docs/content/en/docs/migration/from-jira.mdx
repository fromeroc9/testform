# Migration from Jira / Zephyr / QMetry

Learn how to import existing issues and test cases from Jira or GitHub Projects into the Testform state ledger without regenerating remote IDs.

## The `testform import` Command

The `import` command binds a declarative test case authored in a local `.feature` file to an existing external entity in your QA platform:

```bash
testform import <resource_address> <remote_id>
```

## Step-by-Step: Importing from GitHub Issues

1. **Declare Local Feature:** Create `tests/features/login.case.feature` with identity tag `@tc-login-001`.
2. **Execute Import:**
   ```bash
   npx testform import "tests/features/login.case.feature::@tc-login-001" "142"
   ```
3. **Execution Output:**
   ```text
   Importing remote issue #142 as 'tests/features/login.case.feature::@tc-login-001'...
   Fetching metadata from GitHub Issues API...
   Computing SHA-256 state hash...
   Resource successfully registered into state ledger.
   ```
4. **Verify Plan:**
   ```bash
   npx testform plan
   ```
   Expected output:
   ```text
   Plan: 0 to add, 0 to change, 0 to destroy.
   Your local specifications and remote QA tracker are in complete synchronization.
   ```

# Test Runners Integration

Bridge declarative test specifications with real-world end-to-end and component test runners including Playwright, Cypress, and Vitest.

## Playwright Integration

Playwright is the recommended runner for browser-based end-to-end certification:

```typescript
// tests/e2e/auth.spec.ts
import { test, expect } from '@playwright/test';

test.describe('@tc-auth-001 User authentication', () => {
  test('Successful login with valid credentials', async ({ page }) => {
    await page.goto('/login');
    await page.fill('input[type="email"]', 'admin@company.com');
    await page.fill('input[type="password"]', 'Secret123!');
    await page.click('button:has-text("Sign In")');

    await expect(page).toHaveURL('/dashboard');
    await expect(page.locator('.welcome-banner')).toContainText('Welcome');
  });
});
```

## Orchestration via `testform suite`

When executing `testform suite -tags="@smoke"`, Testform:
1. Resolves the `@smoke` query to matching feature files.
2. Dispatches `npx playwright test --grep "@tc-auth-001"`.
3. Ingests execution timings, stack traces, and screenshots, registering the immutable `@tr-[id]` run artifact.

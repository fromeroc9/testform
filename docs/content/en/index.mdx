## Get Started in 60 Seconds

Adopt Testform in your existing project in 4 simple steps:

<Steps>
### 1. Install Testform
```bash
npm install -g @fromeroc9/testform
```

### 2. Initialize Your Workspace
```bash
testform init
```
Set up the state backend (Local, OCI, AWS S3, or Azure) and connect your tracking platforms (GitHub Projects V2, GitLab, or Jira).

### 3. Plan Your Tests Speculatively
```bash
testform plan
```
Calculates the dependency graph and reviews what resources will be added or updated before making any real changes.

### 4. Reconcile and Run Your Test Runners
```bash
testform apply -auto-approve
testform suite
```
Applies state atomically with distributed locking and launches your automated Playwright, REST API, and K6 suites.
</Steps>

## Quickstart in 60 Seconds

Start managing your QA infrastructure as code in 4 simple steps:

<Steps>
### 1. Install Testform CLI
Install the package globally via npm:
```bash
npm install -g @fromeroc9/testform
```

### 2. Initialize Your Repository
Create your declarative `main.yml` configuration and initialize backends and providers:
```bash
testform init
```

### 3. Preview Speculative Changes
Inspect your reconciliation plan before touching any resources:
```bash
testform plan
```

### 4. Apply State and Run Suites
Atomically synchronize with your platform and trigger the execution matrix:
```bash
testform apply -auto-approve
testform suite tags "[@smoke]"
```
</Steps>

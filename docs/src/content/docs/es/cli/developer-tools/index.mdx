# Herramientas de Desarrollo (Developer Tools)

Utilidades operativas para desarrolladores e ingenieros de calidad que optimizan el formateo, la validacion, el analisis y el reporte de pruebas.

## Comandos Disponibles

- **[`testform suite`](./suite):** Orquesta la ejecucion de suites de prueba automatizadas mediante ejecutores reales (Playwright, Cypress, Vitest).
- **[`testform validate`](./validate):** Valida de forma estatica la sintaxis de archivos `.feature` y las politicas de gobernanza.
- **[`testform fmt`](./fmt):** Reformatea archivos Gherkin y configuraciones YAML segun las convenciones canonicas de estilo.
- **[`testform diff`](./diff):** Muestra diferencias detalladas linea por linea entre las especificaciones locales y el estado registrado.
- **[`testform show`](./show):** Inspecciona archivos de plan binarios o instantaneas de estado en formato legible para humanos o JSON.
- **[`testform query`](./query):** Realiza consultas avanzadas sobre los recursos del repositorio utilizando expresiones de tags y metadatos.
- **[`testform graph`](./graph):** Genera la representacion visual del Grafo Aciclico Dirigido (DAG) en formato DOT o Mermaid.
- **[`testform report`](./report):** Genera informes ejecutivos y de cumplimiento en formatos HTML, Markdown o JUnit XML.

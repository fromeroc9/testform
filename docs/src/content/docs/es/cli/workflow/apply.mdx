# `testform apply`

```bash
testform [opciones globales] apply [opciones] [archivo-de-plan]
```

El comando `testform apply` ejecuta las acciones propuestas en un plan de Testform. Sincroniza el estado deseado con el Provider activo (creando, modificando o cerrando incidencias en GitHub, Jira, etc.) y actualiza `testform.state` al finalizar.

# `testform workspace`

```bash

```

## Subcomandos

### 1. `testform workspace list`
Enumera todos los workspaces existentes. Un asterisco `*` indica el workspace activo:
```bash

  production
```

## Aislamiento de Estado en Backends Remotos

Al utilizar un backend remoto (como AWS S3), Testform organiza los estados de los workspaces bajo prefijos separados:
- Workspace `default`: `mi-bucket/testform.state`
- Workspace `staging`: `mi-bucket/env:/staging/testform.state`
- Workspace `production`: `mi-bucket/env:/production/testform.state`

# Sesiones y Espacios de Trabajo (Sessions & Workspaces)

Comandos para gestionar multiples entornos paralelos, sesiones de autenticacion y ambientes efimeros de prueba.

## Comandos Disponibles

- **[`testform workspace`](./workspace):** Administra entornos paralelos aislados con ledgers de estado independientes (`list`, `new`, `select`, `delete`).
- **[`testform login` / `testform logout`](./login-logout):** Inicia y cierra sesiones de autenticacion con proveedores en la nube y repositorios remotos.
- **[`testform ephemeral`](./ephemeral):** Crea, conecta y destruye entornos efimeros de prueba para validaciones temporales en ramas de corta duracion.

# Datos Sensibles (Sensitive Data)

Puedes marcar cualquier valor en el bloque `outputs:` con el atributo `sensitive: true`:

```yaml

  total_cases:
    value: "${testcase.*.count}"

  service_account_token:
    value: "${var.jwt_auth_secret}"

```

### Comportamiento en Consola
Cuando ejecutas `testform plan`, `testform apply` o `testform output`:

```text
Changes to Outputs:
  + total_cases           = 14
  + service_account_token = (sensitive value)
```

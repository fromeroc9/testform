## DeclaraciÃ³n en `main.yml`

Los providers se configuran en el archivo principal **`main.yml`**:

```yaml
# main.yml
testform:
  required_version: ">= 1.0.0"
  backend:
    local:
      path: "./testform.state"

provider:
  github:
    owner: "mi-organizacion"
    repository: "mi-sistema-web"
    token_env: "GITHUB_TOKEN"
  jira:
    host: "mi-empresa.atlassian.net"
    project_key: "QA"
    email: "qa-team@empresa.com"
```

## InicializaciÃ³n del Provider (`testform init`)

Antes de ejecutar un plan, `testform init` autentica y valida el provider configurado:

```bash
testform init
```

Durante el `init`:
1. Verifica las credenciales de acceso (tokens de entorno como `GITHUB_TOKEN` o `GITLAB_TOKEN`).
2. Configura el backend de estado y el archivo de bloqueo concurrente (`.lock`).
3. Comprueba el acceso al repositorio y a los tableros del proyecto.

A diferencia de Terraform donde usualmente requieres un bucket AWS S3 o GCS externo, **Testform permite utilizar el propio repositorio de GitHub como un bucket de estado**:

El backend de GitHub almacena el ledger en una rama Git dedicada (por defecto `testform-state` o `env/<workspace>/...`) y gestiona el archivo `testform.state.lock` mediante la API de Git con comprobaciÃ³n optimista de SHA.

```yaml

  required_version: ">= 1.0.0"
  backend:
    github:
      owner: "fromeroc9"
      repository: "testform"
      branch: "testform-state"          # Rama que actÃºa como bucket de almacenamiento
      path: "production.testform.state" # Ruta del objeto de estado

```

### CaracterÃ­sticas del Backend GitHub
- **Sin Infraestructura Externa:** No necesitas crear cuentas de AWS ni configurar buckets de S3.
- **Historial Completo de Versiones:** Cada `testform apply` crea un commit firmado en la rama del estado con su SHA-256.
- **Optimistic Locking:** Adquiere un bloqueo creando un archivo temporal `.lock` en la rama; si otro proceso intenta aplicar en paralelo, Testform aborta con error de bloqueo.

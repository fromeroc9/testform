# Actualizacion de Ledger de Estado

Procedimientos seguros para realizar copias de seguridad, actualizar esquemas de estado y transferir ledgers entre diferentes proveedores de nube.

## Migracion entre Proveedores de Backend

Si deseas migrar tu archivo de estado desde almacenamiento local a un bucket de AWS S3 o OCI:

1. **Obtener el Estado Actual:**
   ```bash
   npx testform state pull > backup.state
   ```
2. **Actualizar `testform.yml`:** Modifica el bloque `backend` con la configuracion del nuevo proveedor cloud (ejemplo: S3 o OCI).
3. **Inicializar y Empujar el Estado:**
   ```bash
   npx testform init -migrate-state
   ```
   Testform detectara el estado existente y transferira todos los registros al nuevo backend remoto de forma atomica.

## Copias de Seguridad y Recuperacion

Es recomendable respaldar el estado antes de cambios estructurales:

```bash
# Guardar copia de seguridad local
npx testform state pull > state-backup-$(date +%Y%m%d).json
```

# GitLab CI/CD Pipeline

Configura la conciliacion declarativa de Testform en pipelines de GitLab CI.

## Archivo de Configuracion (.gitlab-ci.yml)

```yaml
stages:
  - validate
  - plan
  - apply

variables:
  TESTFORM_VERSION: "1.0.0"

default:
  image: node:20
  before_script:
    - npm ci

validate:
  stage: validate
  script:
    - npx testform validate
  rules:
    - if: $CI_PIPELINE_SOURCE == "merge_request_event"
    - if: $CI_COMMIT_BRANCH == $CI_DEFAULT_BRANCH

plan:
  stage: plan
  script:
    - npx testform plan -out=testform.plan.bin
  artifacts:
    name: "testform-plan-$CI_COMMIT_SHORT_SHA"
    paths:
      - testform.plan.bin
    expire_in: 1 week
  rules:
    - if: $CI_PIPELINE_SOURCE == "merge_request_event"

apply:
  stage: apply
  script:
    - npx testform apply -auto-approve
  rules:
    - if: $CI_COMMIT_BRANCH == $CI_DEFAULT_BRANCH
```

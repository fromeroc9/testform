# Ecosistema de Integraciones

Conecta Testform con tus pipelines de entrega continua y tus herramientas de automatizacion de pruebas favoritas.

## Integraciones Disponibles

- **[GitHub Actions Pipeline](./ci-cd-github):** Workflow completo con generacion de planes en Pull Requests, comentarios automaticos y aplicacion al hacer merge.
- **[GitLab CI/CD Pipeline](./ci-cd-gitlab):** Configuracion de pipeline multietapa con gestion segura de variables de entorno y caching.
- **[Integracion con Test Runners](./test-runners):** Conecta casos de prueba declarativos con ejecutores como Playwright, Cypress y Vitest.
- **[Proveedores y Webhooks](./custom-providers):** Publica eventos de ejecucion de pruebas hacia canales de Slack, Datadog o endpoints HTTP personalizados.

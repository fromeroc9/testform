# Guias Practicas y Patrones de Arquitectura

Aprende a configurar Testform para entornos empresariales de alta disponibilidad, equipos distribuidos y arquitecturas de prueba avanzadas.

## Guias Disponibles

- **[Backends Multi-Cloud](./multi-cloud-backends):** Como configurar el almacenamiento del estado en Oracle Cloud Infrastructure (OCI), Amazon S3 con DynamoDB, Azure Blob Storage, Google Cloud Storage y almacenamiento local.
- **[Bloqueo Distribuido de Estado](./state-locking):** Mecanismos de mutex distribuido, duracion de leases y prevencion de colisiones en ejecuciones paralelas de CI/CD.
- **[Pruebas Basadas en Datos](./data-driven):** Diseno de matrices de prueba complejas mediante `Scenario Outline` y tablas `Examples`.
- **[Arquitectura Modular (@module)](./modules):** Reutilizacion de flujos de prueba (como inicio de sesion y checkout) en multiples archivos `.feature`.
- **[Deteccion de Deriva (Drift)](./drift-detection):** Monitoreo continuo y alertas automaticas ante modificaciones manuales en herramientas externas.

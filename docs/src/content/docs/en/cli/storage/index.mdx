# State & Storage

Commands for inspecting, mutating, importing, and unlocking the underlying cryptographic state ledger.

## State and Storage Commands

- **[`testform state`](./state):** Inspects and manages entries stored inside the state ledger (`list`, `show`, `rm`, `pull`, `push`).
- **[`testform import`](./import):** Ingests pre-existing external QA issues and maps them directly to declarative resources.
- **[`testform taint`](./taint):** Marks a specific resource for forced re-creation on the subsequent apply run.
- **[`testform force-unlock`](./force-unlock):** Manually releases an abandoned distributed mutex lock following an aborted pipeline.

# State Ledger Upgrades

Safe operating procedures for state backups, schema version migrations, and transferring state ledgers between cloud backends.

## Migrating Between State Backends

To migrate your state file from local storage to an AWS S3 bucket or OCI Object Storage:

1. **Pull Current State:**
   ```bash
   npx testform state pull > backup.state
   ```
2. **Update `testform.yml`:** Reconfigure the `backend` block with the target cloud provider credentials and bucket.
3. **Initialize with State Migration:**
   ```bash
   npx testform init -migrate-state
   ```
   Testform detects the legacy state and transfers all registered entities to the new backend atomically.

## Backups and Disaster Recovery

Always retain automated snapshots prior to significant refactorings:

```bash
# Export state snapshot
npx testform state pull > state-backup-$(date +%Y%m%d).json
```

# Integrations Ecosystem

Connect Testform seamlessly into your continuous delivery pipelines and test automation frameworks.

## Available Integrations

- **[GitHub Actions Pipeline](./ci-cd-github):** Full production workflow with Pull Request speculative plan previews, PR bot comments, and apply on merge.
- **[GitLab CI/CD Pipeline](./ci-cd-gitlab):** Multi-stage pipeline architecture with secure credential handling and state caching.
- **[Test Runners Integration](./test-runners):** Bridge declarative Gherkin specifications with Playwright, Cypress, and Vitest runners.
- **[Custom Providers and Webhooks](./custom-providers):** Broadcast test run events to Slack, Datadog, or custom webhook endpoints.
